Project Architecture & Refactoring Workflow

Legacy Python Architecture

  • Paradigm: Synchronous, monolithic CLI terminal script (main.py).
  • Interface: Text console with blocking input() loops. Single user only.
  • Persistence: Synchronous file writes to students.json.
  • Extensibility: Cannot integrate with web, mobile apps, or external APIs.

Refactored Node.js & Express Architecture

  • Paradigm: Non-blocking, asynchronous RESTful API Service.
  • Architecture: Layered MVC (Controller → Service → Repository → Storage).
  • Documentation: Interactive Swagger UI (OpenAPI 3.0) for live testing.
  • Integrity: Atomic asynchronous file transactions, structured validation middleware, HTTP status codes.

End-to-End Request Workflow

1 Client Request

Browser UI or Swagger UI executes HTTP request (GET, POST, PUT, DELETE).

2 Middleware Layer

CORS, JSON Parser, Logger, and Input Validation enforce business schemas.

3 Controller

Dispatches sanitized payloads to the business domain layer.

4 Service & Metrics

Validates uniqueness, calculates grades (A+-F), computes statistics.

5 Repository & Storage

Performs atomic async I/O on students.json.

6 Standard Response

Returns standard JSON envelope with HTTP status (200, 201, 400, 404, 409).
